# CCNA Labs

Hands-on networking labs I'm building while studying for the Cisco CCNA (200-301). Each lab is designed and configured by me in Cisco Packet Tracer, and includes the topology, full configs, verification output, and the real problems I ran into along the way.

| # | Lab | Topics | Status |
|---|---|---|---|
| 01 | [Multi-Router Static & Default Routing](01-static-routing/) | IPv4 addressing, connected/local routes, static routes, default routes, two-way reachability, troubleshooting | ✅ Complete |
| 02 | Network Troubleshooting | Finding and fixing planted faults with `show` commands and Simulation mode | 📅 Planned |

**Tools:** Cisco Packet Tracer 8.x · Cisco IOS CLI
